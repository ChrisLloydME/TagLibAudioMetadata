## What you must deliver

The current baseline has strong existing matrices but still missed defects because some public entry points were not tested, validation and execution disagreed, preservation checked values without flags, and counts did not prove execution. Upgrade the architecture so these *classes* of defect are caught inside this repository, rather than adding only another list of special-case tests.

Implement five separate layers:

- **Surface inventory:** stable IDs for all facade and exported bridge signatures, overloads, verification/audio/version modes, raw replace/merge modes, structured sub-surfaces, normalization, erase/wipe and reads/registry. Internal in-place selectors are not public entry points. New/unclassified APIs must fail coverage decisions.
- **Test-owned contract catalog:** scenario IDs, fixture/version, public surface, input/state partition, exact intended ownership, expected native identities/types, unsupported outcomes, normalization and oracle. Production metadata may enumerate claims, but cannot generate golden targets or expected success. Unsupported requires an explicit rejection decision, not `continue` or a skip.
- **Execution adapters:** each invokes one named public API, without coercion/fallback/retry. Facade wrappers and direct bridge calls are separate adapters. - **Builders/oracles:** reuse bounded independent native readers, self-test them and verify every seed before use. Compare edited owners, untouched arrays/duplicates/flags/identity, and audio/sample bytes where supported. Preserve literal oracle vectors; package self-readback alone is insufficient.
- **Evidence gate:** bind actual source/build/test/catalog identities to fresh runs, compare expected/observed scenario sets and framework outcomes, and reject incomplete/stale/mixed/ambiguous evidence. Counts and suite banners are supporting evidence only.
